# projectone

## Visão Geral

Este repositório contém um projeto de análise de dados focado no par de moedas EUR/USD. O objetivo principal é processar dados históricos e realizar análises para identificar padrões ou tendências.

## Conteúdo

- `main.py`: O script principal em Python responsável pela leitura, processamento e análise dos dados.
- `eurusd_data.csv`: Um arquivo CSV contendo dados históricos do par EUR/USD, utilizado como entrada para a análise.
