# projectone

## Visão Geral

Este repositório contém um projeto de análise de dados focado no par de moedas EUR/USD. O objetivo principal é processar dados históricos e realizar análises para identificar padrões ou tendências.

## Conteúdo

- `main.py`: O script principal em Python responsável pela leitura, processamento e análise dos dados.
- `eurusd_data.csv`: Um arquivo CSV contendo dados históricos do par EUR/USD, utilizado como entrada para a análise.

## Como Rodar

Para executar este projeto, siga os passos abaixo:

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/TheLastRenato/projectone.git
   cd projectone
   ```

2. **Instale as dependências (se houver):**
   Embora não haja um `requirements.txt` explícito, é provável que o script utilize bibliotecas comuns de análise de dados em Python, como `pandas` e `numpy`. Você pode instalá-las com:
   ```bash
   pip install pandas numpy
   ```

3. **Execute o script principal:**
   ```bash
   python main.py
   ```

## Tecnologias Utilizadas
